## 📘 About the Project

FurMatch is a simple and user-friendly platform designed to help pet owners and breeders connect and find suitable breeding partners for their pets. It solves common challenges in pet breeding by using technology to make connections easier, more transparent, and more reliable. The platform encourages individuals with similar goals to communicate and collaborate responsibly.

Aligned with the **United Nations Sustainable Development Goals — 
FurMatch supports responsible pet care, ethical breeding, and building collaborations among pet owners and breeders.

To promote trust, FurMatch requires all users to complete an **email verification process** before gaining access. This helps ensure authenticity and prevents fake or unsafe accounts.

Users can create detailed pet profiles containing breed information and relevant background details. These profiles become part of the community, allowing other users to browse and initiate conversations for possible breeding opportunities.

FurMatch also provides tools to enhance convenience and safety, such as privacy controls, password resets, account resets, and a built-in Help & Support/Standards section. These reflect FurMatch’s commitment to user empowerment and promoting a safe breeding community.

## ✨ Features

### 👤 **User & Account**
- Email registration with **email verification**
- Login for verified users only
- Edit user profile information
- Reset password (Privacy settings)
- Reset account (deletes pets & messages but keeps login credentials)

### 🐶 **Pet Management**
- Add pet profiles (dog or cat only)
- Edit pet information
- Delete pet profiles
- View other users' pets listed for breeding
- You cannot see your own pet in the public pet list

### 💬 **Messaging System**
- Message pet owners/breeders directly
- Real-time conversation history
- “Message Owner” button on each pet card

### 📝 **Feedback & Support**
- Submit feedback to developers/admins
- Admin can respond to or delete feedback
- Built-in **Help Center & Standards**

### 🔐 **Security & Privacy**
- Email verification before login
- Secure Supabase authentication
- No monetary transactions
- Follows ethical and responsible pet breeding principles
